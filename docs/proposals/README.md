# 提案区（Proposals）

本目录存放 **待 owner 审核** 的 ADR / KB 提案，便于在不违反“ADR / KB 必须先批准后写入”规则的前提下逐条讨论。

流程：

1. Agent 在 `docs/proposals/` 创建 `ADR-xxx-<slug>.md` 或 `KB-xxx-<slug>.md`。
2. Agent 在对话中向 owner 列出提案清单、说明影响。
3. owner 明确同意后，agent 才把文件移动到 `docs/adr/` 或 `docs/kb/`，并更新索引 / 状态。
4. 未获批准的提案保持在本目录，状态标记为“待批准”。
